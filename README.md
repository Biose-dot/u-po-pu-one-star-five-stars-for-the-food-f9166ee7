# One Star, Five Stars for the Food

An alien tourist hands planet Earth a one-star review — charging for water, worshipping a glowing rectangle, calling sitting in traffic "freedom" — then admits the tacos were so good it nearly gave Earth a second star. One sentence, 157 characters, complaint and food compliment in the same breath.

> One star: you charge for water, worship a glowing rectangle, and call sitting in traffic freedom, but the tacos were so good I nearly gave you a second star.

`main.py` writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
